# MyMarket


Georgios Tyrptsis (Developed as a collaborative academic project at Aristotle University of Thessaloniki)



Εισαγωγή στο Project
   
Το project "MyMarket" είναι μια εφαρμογή που προορίζεται για τη διαχείριση ενός σουπερμάρκετ, προσφέροντας τόσο ένα περιβάλλον για διαχείριση των προϊόντων όσο και για τους πελάτες να πραγματοποιούν αγορές και να παρακολουθούν την ιστορικότητα των παραγγελιών τους. Η εφαρμογή περιλαμβάνει δύο βασικά πάνελ: το πάνελ διαχείρισης για τους διαχειριστές και το πάνελ για τους πελάτες.

Χαρακτηριστικά και Λειτουργίες:

1. Διαχείριση Χρηστών: 

Οι χρήστες μπορούν να δημιουργούν λογαριασμούς ως πελάτες ή διαχειριστές. Το σύστημα παρέχει τη δυνατότητα εισόδου (login), εγγραφής νέου χρήστη και διαχείρισης χρηστών.

Διαχειριστές:

Συνδέονται στην εφαρμογή.
Μπορούν να προσθέτουν, επεξεργάζονται ή διαγράφουν προϊόντα από το απόθεμα.
Βλέπουν όλα τα διαθέσιμα προϊόντα του καταστήματος εκτελούν αναζητήσεις.


Πελάτες:

Δημιουργούν λογαριασμό ή εισέρχονται με τον υπάρχοντα λογαριασμό τους.
Προσθέτουν προϊόντα στο καλάθι τους.
Υποβάλλουν παραγγελίες αφού ελέγξουν τα προϊόντα στο καλάθι τους.
Παρακολουθούν το ιστορικό των παραγγελιών τους.


2. Διαχείριση Προϊόντων:

Προσθήκη Προϊόντος: Οι διαχειριστές μπορούν να προσθέτουν νέα προϊόντα.
Επεξεργασία Προϊόντος: Δυνατότητα επεξεργασίας των χαρακτηριστικών των προϊόντων.
Διαγραφή Προϊόντος: Αφαίρεση προϊόντων από το απόθεμα.
Αναζήτηση Προϊόντων: Η αναζήτηση των προϊόντων μπορεί να γίνει είτε με βάση τον τίτλο είτε με βάση την κατηγορία.

3. Καλάθι Αγορών:

Οι πελάτες μπορούν να προσθέτουν προϊόντα στο καλάθι τους και να ενημερώνουν τις ποσότητες.
Υποβολή παραγγελίας αφού ελέγξουν τα προϊόντα του καλαθιού τους και την ποσότητα των προϊόντων.

4. Ιστορικό Παραγγελιών:

Οι πελάτες έχουν πρόσβαση στο ιστορικό των παραγγελιών τους και μπορούν να δουν τις λεπτομέρειες των παραγγελιών τους όπως τα προϊόντα που αγόρασαν, την ποσότητα και το σύνολο της παραγγελίας.


5. Αρχιτεκτονική

Η εφαρμογή χρησιμοποιεί τις αρχές του αντικειμενοστραφούς προγραμματισμού (Object-Oriented Programming - OOP) , όπου τα αντικείμενα αντιπροσωπεύουν χρήστες, προϊόντα, παραγγελίες και το καλάθι αγορών. 

Οι βασικές κλάσεις περιλαμβάνουν:

User: Η κλάση που αναπαριστά τους χρήστες του συστήματος (διαχειριστές ή πελάτες).

UserManager: Η κλάση που διαχειρίζεται τους χρήστες του συστήματος, όπως την εγγραφή, την αποθήκευση και την επαλήθευση των στοιχείων τους για το login.

Admin: Η κλάση που αναπαριστά τον διαχειριστή του συστήματος.

Customer: Η κλάση που αναπαριστά έναν πελάτη του συστήματος.

Product: Η κλάση που αναπαριστά τα προϊόντα που πωλούνται στο σουπερμάρκετ.

ShoppingCart: Η κλάση που διαχειρίζεται το καλάθι αγορών ενός πελάτη.

Order: Η κλάση που αποθηκεύει τις παραγγελίες που έχουν γίνει από πελάτες.

OrderHistory: Η κλάση που αναπαριστά το ιστορικό των παραγγελιών, αποθηκεύοντας όλες τις παραγγελίες και παρέχοντας τη δυνατότητα προβολής τους.

Supermarket: Η κλάση που διαχειρίζεται τα δεδομένα του σουπερμάρκετ, όπως χρήστες, προϊόντα, παραγγελίες και καλάθι αγορών.

SupermarketGUI: Η γραφική διεπαφή χρήστη
